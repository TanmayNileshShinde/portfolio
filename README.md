## 🎨 3 Interactive 3D Cyber Themes

Switch between 3 custom visual worlds and acoustics directly in the HUD header or via the terminal (`theme <name>`):

1. **🏎️ Oracle Red Bull Racing / F1 (Max Verstappen #1)**
   - *Palette:* Racing Bull Yellow (`#ffc800`), Championship Red (`#e10600`), Dutch Orange (`#ff5500`), Navy Blue (`#040817`).
   - *3D World:* Aerodynamic vortex core, triple concentric aero rings, orbiting Max Verstappen `#1` satellite, high-velocity particle wind.
   - *Cockpit:* Interactive 342+ km/h speed gauge, 12,180 RPM tachometer, DRS status, and pit stop simulator.
   - *Audio:* V6 Turbo-hybrid throttle blip & DRS whoosh.

2. **🏏 Floodlit Cricket Stadium**
   - *Palette:* Stadium Turf Green (`#00f57a`), Pitch Gold (`#ffd700`), India Royal Blue (`#0070f3`).
   - *3D World:* 3D Leather Cricket Ball with genuine seam rotation, floodlight boundary halos, and orbiting 6-run satellite.
   - *Cockpit:* Live 152.4 km/h speed gun, Wankhede match scoreboard, exit velocity meter, and monster six hit trigger with confetti!
   - *Audio:* Crisp willow-leather bat crack & stadium wave.

3. **🎮 Cyber Gaming Arcade / React Nexus**
   - *Palette:* Cyber Magenta (`#f72585`), Neon Cyan (`#4cc9f0`), Hyper Violet (`#7209b7`).
   - *3D World:* Floating Arcade Hyper-Cube, inner shield sphere, synthwave undulating grid floor, and power-up rings.
   - *Cockpit:* Global high score leaderboards (999,420 PTS), 60 FPS locked, 16x combo multiplier, and arcade power-up coin trigger.
   - *Audio:* 8-bit retro arcade coin chime & laser blaster.

## 💻 Interactive TANMAY-OS CLI Shell

Embedded directly into the site with full keyboard navigation (↑/↓ command history) and synthesized cyber audio:
* `help` — Directives directory
* `projects` — Lists all 10 verified live Vercel deployments
* `skills` — Architectural proficiency matrix
* `f1` — Oracle Red Bull Racing & Max Verstappen #1 telemetry burst
* `cricket` — Floodlit stadium live match radar & Wankhede commentary
* `gaming` — React Nexus arcade metrics & high scores
* `theme <redbull|cricket|gaming>` — Switches the 3D WebGL scene and site tokens
* `sudo hire` — **Triggers a celebratory confetti explosion and priority dispatch alert!**

## 🛠️ Local Setup

```bash
# Clone repository
git clone https://github.com/TanmayNileshShinde/portfolio.git

# Navigate into project directory
cd portfolio

# Install dependencies
npm install

# Start local development server with HMR
npm run dev

# Build production bundle
npm run build
```

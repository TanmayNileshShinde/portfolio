## 🌟 Key Architectural Features

- **⚛️ Three.js WebGL Multi-Universe Core:**
  - **Quantum Core:** Floating crystalline wireframe icosahedron with inner pulsating core, triple concentric gyroscopic rings, orbiting satellites, and interactive raycasting.
  - **Cyber Grid Horizon:** Undulating neon topography grid with oscillating sine-wave vertex displacements.
  - **Neural Constellation:** Synaptic brain network of drifting nodes with dynamic Euclidean distance lines.
  - **Particle Nebula Starfield:** Over 2,200 additive particles reacting to cursor parallax and scroll depth.

- **🏎️ Live Formula 1 Telemetry Cockpit:**
  - Real-time vehicle speed gauge (324 - 352 km/h), RPM tachometer (11,850+ RPM), DRS active status, and personal best sector delta tracker.
  - Interactive test triggers (`Sim Acceleration Burst` & `Simulate Pit Strategy`).

- **💻 Interactive TANMAY-OS v2.6 Shell:**
  - Authentic CLI terminal with command history (↑/↓ arrows) and sound effects.
  - Commands: `help`, `about`, `projects`, `skills`, `f1`, `stats`, `theme`, `clear`, and `sudo hire` (triggers celebratory confetti!).

- **🗂️ 3D Perspective Tilt Project Cards & Architecture Modal:**
  - Real-time 3D cursor tilt physics with dynamic specular lighting sheen.
  - Dedicated architecture modal detailing system dataflows, metrics, and direct links to live deployments and GitHub repositories.

- **🔊 Procedural Web Audio API Synthesizer:**
  - 100% synthesized procedural sound effects (zero audio assets to download).
  - Hover hums, UI clicks, terminal keystrokes, and mode-switch sweeps with HUD toggle switch.

- **🎯 Cyber Cursor & Specular Glare:**
  - Smooth lerped glowing pointer with ring follower and magnetic element locking.

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/TanmayNileshShinde/portfolio.git

# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Run the local development server (with HMR)
npm run dev

# Build production bundle
npm run build
```

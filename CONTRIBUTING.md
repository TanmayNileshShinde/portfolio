# Contributing to Tanmay Shinde's Portfolio

Thank you for contributing to this developer portfolio.

## Aesthetics & Design System
- Dark-mode primary color scheme (`#09090b`) with modern neon accents.
- Responsive breakpoints for mobile, tablet, laptop, and ultra-wide viewports.
- Framer Motion animation configurations should be clean and smooth with accessible `prefers-reduced-motion` considerations.

## Pull Request Guidelines
- Verify build with `npm run build` before opening a pull request.
- Keep dependency additions minimal to preserve lightweight page load times.

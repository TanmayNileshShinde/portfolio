# Security Policy

**Tanmay Nilesh Shinde Portfolio**

---

## 🔒 Security Practices

1. **Client-Side WebGL Rendering:** 3D scenes (Three.js) run purely client-side on hardware-accelerated canvas.
2. **Environment Variable Protection:** API keys and environment variables are strictly managed through environment variables and never committed to source.
3. **No Unsafe External Scripts:** External script dependencies are minimized and sanitized.
